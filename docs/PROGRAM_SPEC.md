# Declassify Station 전시 프로그램 명세 (v1.0)

> 대상: AX Day 2026 "Copilot Secret Agent HQ" 부스에서 돌리는 미션 카드형 전시 프로그램
> 기준: `prototype/station.html` (웹 게시용 원본), `prototype/index.html` (현장 PC에서 바로 여는 파일) 현재 구현
> 이력: v0.1 초안 → v0.2 Codex 리뷰 13건 반영 → v0.3 미션 카드 3건 → **v1.0 현재 시안 기준으로 전면 정리** (13절 변경 기록)

## 2. 화면 흐름

```
[시작 화면] --START--> [미션 선택 + 본부 지령] --카드 선택--> [미션 01~03 재생 8단계] --종료--> [시작 화면]
```

### 2-1. 시작 화면
- 레이더 배경, 공식 Copilot 로고, "Copilot SECRET AGENT" 타이틀, TOP SECRET 도장, START 버튼
- START(또는 Space·Enter)를 누르면 효과음과 함께 미션 선택 화면으로 넘어감
- 이 화면에서는 소리가 나지 않음 (브라우저는 첫 터치 전에 소리 재생을 막음)

### 2-2. 미션 선택 + 본부 지령
- 상단 "INCOMING TRANSMISSION · 본부 지령" 상자에 지령 문구가 자막으로 타이핑됨
- 지령 음성(`voice-intro.wav`, 18.4초)이 재생되고, 오프닝 BGM이 작게 깔림
- 지령 문구: "안녕하십니까 Copilot Secret Agent에 오신걸 환영합니다. 당신은 지금부터 삼성화재 곳곳에 비밀리에 활동하는 Copilot Agent를 활용하여 주어진 미션을 수행해야 합니다. 미션을 선택하시길 바랍니다."
- 미션 카드 3장. 카드 터치 또는 1·2·3 키로 선택. 음성 도중에 골라도 됨(음성 중단)

### 2-3. 미션 재생 8단계

| # | 단계 | 화면 | 자동 재생 시간 |
|---|---|---|---|
| 1 | 미션 수령 | 카드가 뒤집히며 지령 문구 타이핑, ACCEPTED 도장 | 7초 |
| 2 | 문제 상황 | 미션별 업무 화면 + "INCIDENT" 문제 요약, Copilot 버튼 등장 | 10초 |

| 4 | 데이터 처리 | Copilot 작업 4단계가 하나씩 체크되고, 업무 화면에서 근거 위치가 노란 박스로 강조됨 | 16초 (클릭 진행 7.8초 + 클릭 대기) |
| 5 | 결과물 생성 | 결과 문서가 줄 단위로 생성, 제목줄에 "Copilot으로 작성됨" | 10초 |

| 7 | 사례 공개 | CASE FILE: 문제→데이터→Copilot 처리→결과물→효과, Before/After 막대, STEAL THIS PROMPT, 적용 가능 부서 | 16초 |

## 3. 진행 방식

### 3-1. 클릭 진행 (기본)
아래 9곳에서 재생이 멈추고, 나머지 화면은 어두워지며 누를 곳에 흰 테두리와 "CLICK" 안내가 뜬다. 해당 부분을 누르거나 **Enter · → · PageDown**(프레젠터 리모컨)으로 진행한다.

| 순서 | 멈추는 순간 | 누를 곳 |
|---|---|---|
| 1 | Copilot 실행 | 업무 화면의 Copilot 버튼 |
| 2 | 요청 보내기 | Copilot 창의 전송 버튼 (안내는 업무 화면 쪽에 점선으로 연결해 표시) |
| 3~6 | 근거 확인 (4회) | 처리 단계마다 강조되는 근거 위치 |
| 7~8 | 사람 검토 (2회) | 결과 문서의 검토할 부분 |
| 9 | 승인 | 결과 문서 (승인 도장) |

- 누를 대상이 화면에서 숨겨져 있으면 업무 화면 전체를 대신 강조해 멈춤이 생기지 않게 한다.

### 3-2. 자동 재생
- 카드 1장만 고르면 끝까지 자동으로 재생된다. 무인 운영용.
- 검토 모드의 "진행: 클릭/자동" 버튼으로 전환하며, 마지막 선택을 브라우저가 기억한다.

## 4. 소리

| 장면 | 파일 | 비고 |
|---|---|---|
| 본부 지령 음성 | `assets/voice-intro.wav` | 재생 중에는 BGM을 원래 크기의 약 1/3로 낮춤 |
| 오프닝 (지령 대기·미션 선택) | `assets/bgm-open.mp3` | Sound4Stock – Spy Agent Mission Music |
| 미션 01 | `assets/bgm-m1.mp3` | music_for_videos – Spy |
| 미션 02 | `assets/bgm-m2.mp3` | Sonican – Secret Agent Loop 2 (Slick Spy) |
| 미션 03 | `assets/bgm-m3.mp3` | Pietix – Spy Agent Action |
| 엔딩 | `assets/bgm-open.mp3` | 처음부터 다시 재생 |

- 장면이 바뀌면 앞 곡을 서서히 줄이고 다음 곡을 서서히 키운다. 곡보다 미션이 길면 반복 재생.
- 음원 파일 재생에 실패하면 브라우저에서 직접 합성하는 대체 BGM이 나온다. 음성 파일이 없으면 브라우저 내장 한국어 남성 음성을 쓴다.
- 일시정지하면 소리도 멈춘다. 검토 모드의 "소리" 버튼으로 끌 수 있다.
- 음원은 모두 Pixabay(Pixabay Content License, 출처 표기 불필요).

## 5. 화면 모드 · 조작

### 5-1. 현장 모드
- 들어가기: 검토 모드의 **현장 모드** 버튼, **K 키**, 또는 주소 끝에 `#kiosk`
- 검토용 버튼·설명을 숨기고 전시 화면만 전체 화면으로 띄운다. 화면 비율이 16:9가 아니면 위아래(또는 좌우)를 검게 채운다.
- 나가기: **K 키** (전체 화면만 풀려면 Esc)
- 마지막 상태를 기억하므로, 현장 PC에서 한 번 켜 두면 다시 열어도 현장 모드로 시작한다.

### 5-2. 키보드 (스태프용)

| 키 | 동작 |
|---|---|
| Space / Enter | 시작 화면에서 START |
| 1 · 2 · 3 | 미션 선택 |
| Enter · → · PageDown | 클릭 대기 중이면 다음 단계 |
| → / ← | 단계 이동 (클릭 대기가 아닐 때) |
| Space | 재생 중 일시정지 / 계속 |
| K | 현장 모드 켜기·끄기 |

## 6. 콘텐츠 교체 방법

- 미션 내용은 `station.html`의 `MISSIONS` 배열 1곳에 모여 있다. 미션마다 다음 항목을 바꾼다.
  - 카드 문구, 지령(`directive`), 문제 요약(`pain`)
  - 업무 화면(`blank`)과 결과물(`result`) HTML
  - 첨부 파일 목록(`files`), 프롬프트(`prompt`)와 강조 키워드(`keywords`)
  - 처리 4단계(`steps`: 제목·설명·근거 태그·강조 위치), 사람 검토 2곳(`checks`)
  - 사례 공개(`cs`): 5단계 문구, Before/After 수치, 적용 가능 부서, 인용
- 수정 후 할 일
  1. `index.html`을 다시 만든다 (`station.html` 앞뒤에 문서 머리말을 붙인 파일).
  2. **문구에 새 글자가 들어가면 글꼴 파일을 다시 만든다.** 오프라인 글꼴은 현재 문구에 쓰인 글자만 담고 있어서, 새 글자는 다른 글꼴로 보일 수 있다 (8절).
  3. 클릭 진행으로 세 미션을 끝까지 돌려 강조 위치와 메모 위치를 확인한다.
- 실제 사례 수집 양식은 제안서 부록 8-1을 쓴다.

## 8. 현장 PC · 운영

| 항목 | 기준 |
|---|---|
| 디스플레이 | 16:9 가로 (55" 이상 권장), 터치 사용 시 터치 디스플레이 |
| PC | 최신 Chrome 또는 Edge가 돌아가는 Windows PC. 예비 PC 1대에 같은 파일 복사 |
| 실행 | `prototype` 폴더를 통째로 PC에 복사 → `index.html#kiosk`를 브라우저로 열기 |
| 자동 실행 권장 | 브라우저 키오스크 실행 옵션(`--kiosk --autoplay-policy=no-user-gesture-required`)으로 시작 프로그램 등록 |
| OS 설정 | 절전·화면보호기·알림·자동 업데이트 재부팅 끄기, 화면 해상도와 방향 고정 |
| 오프라인 | 인터넷 없이 동작 확인 완료 (글꼴·로고·음원 모두 로컬) |
| 글꼴 재생성 | 문구를 바꾼 경우, 인터넷이 되는 PC에서 Google Fonts의 `text=` 옵션으로 쓰인 글자만 담은 woff2를 다시 받는다 |

### 8-1. 현장 확인 체크리스트

## 11. 비기능 요건
- 인터넷 없이 동작, 외부 요청 0건
- 1600×900 기준 화면을 디스플레이 크기에 맞춰 확대 (글자 최소 크기는 1.5m 거리 가독성 기준)
- 오류가 나도 검은 화면을 띄우지 않음: 누를 대상이 없으면 대신 진행, 음원이 실패하면 대체 BGM, 음성 파일이 없으면 내장 음성

## 12. 실행 방식에 대한 결정
v0.2에서는 "재생 셸 + 사전 제작 MP4 본편" 구조를 합의했지만, v1.0에서는 **웹 화면이 실시간으로 동작하는 방식** 하나로 간다.
- 클릭 진행(9곳 멈춤, 누른 위치에 따라 다음 장면)이 핵심 요구가 되었고, 이는 미리 만든 영상으로는 구현하기 어렵다.
- 사례 문구를 바꿀 때 영상을 다시 렌더링할 필요 없이 데이터만 고치면 된다.
- 대신 현장 PC 1대로 세 미션을 충분히 돌릴 수 있는지 실제 장비 테스트로 확인한다 (8-1).
