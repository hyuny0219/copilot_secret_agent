# 원본 기획 요청 (Brief)

> 이 문서는 `AX_Day_2026_Copilot_Secret_Agent_HQ_Proposal.md`를 만들 때 쓴 원본 요청입니다.
> 리뷰하는 사람(사람이든 AI든)은 제안서가 이 요청을 얼마나 충실히 충족하는지 이 문서를 기준으로 판단합니다.

## 역할
Fortune 500 기업의 전시/이벤트 기획 총괄이자 Microsoft Copilot 기반 AX Day 부스를 설계하는 Creative Director.

## 배경
"AX Day 2026"에서 Microsoft Copilot 우수사례를 소개하는 부스를 운영한다.

일반적인 AI 전시는 "어떤 agent가 만들어졌다 / 어떤 결과가 나왔다 / 어떤 효과가 있었다"까지만 보여준다.
방문객은 결국 다음을 궁금해한다.
- 그래서 실제로 뭘 한 거지?
- Copilot은 어떻게 활용한 거지?
- 어떤 데이터를 보고 어떤 결과를 만들었지?
- 우리 부서도 적용할 수 있나?

실제 Copilot 체험존은 라이선스, 계정, 기업 데이터 접근 제한, 개인정보, 운영 복잡도, 대기열 문제로 운영하기 어렵다.
따라서 이번 부스는 "Copilot 사용 체험존"이 아니라 **"Copilot 활용사례를 이해시키는 시각화 전시관"** 이다.

## 핵심 컨셉
- 컨셉명 후보: Copilot Secret Agent HQ / Secret Agent Archive / Secret Agent Case File / Agent Intelligence Center
- 세계관: Copilot Agent = 비밀요원. 각 우수사례 = 하나의 Secret Agent Case.
  - 예: Agent Black(회의 요약), Agent Blue(문서 탐색), Agent Gold(보고서 생성), Agent Red(VOC 분석)
- 방문객은 비밀정보 열람 권한을 받아 각 Agent가 어떤 업무를 했고, 어떤 데이터를 썼고, 어떤 결과물을 만들었는지 시각적으로 탐색한다.

## 제약조건
- 일반적인 전시 부스를 제안하지 말 것.
- "제목 / 설명 / 효과" 형태의 포스터 나열 금지.
- 방문객이 "아, 이렇게 활용하는구나"를 직관적으로 이해하는 전시 경험을 설계할 것.

## 요구 결과물
1. 부스 전체 컨셉 제안: 컨셉명, 스토리라인, 세계관, 방문객 여정
2. 활용사례 전시 방식: **문제 → 사용 데이터 → Copilot/Agent 처리 과정 → 결과물 → 효과** 흐름을 시각적으로 어떻게 표현할지
3. (원문 번호 누락)
4. 사례 카드 디자인: 예) CASE #001 회의요약 Agent를 와이어프레임 수준까지 묘사
5. 인터랙션 없이도 참여감을 주는 방법: Start만 누르면 그 뒤로 알아서 보여주는 방식
6. Secret Agent 테마와 자연스럽게 연결되는 장치: 보안등급, 기밀문서, 사건파일, 조사보고서, Intelligence Map 등
7. 최종 권장안: 운영 현실성까지 고려해 가장 추천하는 1개 안과 그 이유

## 출력 형식
- 전문 전시기획 제안서 수준
- 컨셉, 동선, 공간, 디자인, 메시지, 관람 경험을 통합적으로 설계
- **"Copilot 우수사례를 어떻게 시각적으로 보여줄 것인가"를 가장 깊게 다룰 것**
