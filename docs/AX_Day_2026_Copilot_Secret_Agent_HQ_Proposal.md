## 0. Executive Summary

### 문제 정의
기존 AI 전시는 **"무엇을 만들었고(What) → 얼마나 좋아졌다(Effect)"** 만 보여준다.
방문객이 정말 궁금한 것은 그 사이에 비어 있는 **"어떻게(How)"** 다.

```
  기존 AI 전시          [Agent 이름] ──────────── ? ? ? ──────────── [효과 30% ↑]
                                       (블랙박스: 방문객이 이해 못 하는 구간)

  이번 부스             [사건] → [증거(데이터)] → [작전(프롬프트·처리)] → [회수 문서(결과물)] → [작전 성과(효과)]
                                       (전부 공개: 방문객이 "아, 이렇게 하는구나")
```

### 핵심 아이디어
**"Secret Agent의 비밀은 '능력'이 아니라 '수법'이다."**
Copilot 우수사례의 진짜 기밀은 Agent의 이름이 아니라 **어떤 데이터를, 어떤 지시(프롬프트)로, 어떤 순서로 처리했는가** 이다.
이 부스는 그 **수법을 '기밀 해제(Declassify)'하는 경험** 을 판다.

### 한 문장 컨셉
> 방문객은 AX 정보국의 **임시 열람 요원(Handler)** 으로 임명되어, 4명의 Copilot 요원이 해결한 **사건 파일을 기밀 해제** 하며
> "문제 → 데이터 → 처리 → 결과물 → 효과"의 전 과정을 **눈으로 추적** 한다. 그리고 마지막에 **"우리 부서의 사건"** 을 의뢰하고 나간다.

### 권장안 요약 (상세는 7장)
**하이브리드형 "Declassify Station + Evidence Wall"**
- 물리적 **사건파일 폴더(아날로그)** 로 손에 잡히는 이해를 주고,
- **Start 버튼 하나** 로 90초 자동 재생되는 **작전 재현(Operation Replay) 스크린** 으로 처리 과정을 보여주며,
- 계정·라이선스·실데이터 없이 **사전 제작 콘텐츠만으로 100% 운영** 한다.

### 1-2. 세계관

#### 방문객의 역할: **임시 열람 요원 (Handler)**
- 방문객은 '구경꾼'이 아니라 **이 사건들을 검토하고 자기 부서에 적용할지 판단하는 담당관** 이다.
- 이 역할 부여가 중요한 이유: 관람의 목적을 "구경"에서 **"판단(우리도 쓸 수 있나?)"** 으로 바꾸기 때문.

#### 세계관 핵심 규칙 (콘텐츠 제작 원칙)
1. **요원은 초능력자가 아니다.** 모든 사건은 "직원이 무엇을 시켰고, Copilot이 무엇을 읽었는지"가 반드시 공개된다. (AI 과장 금지)
2. **증거 없는 성과는 없다.** 모든 효과 수치는 Before/After 증거물과 함께 제시한다.
3. **모든 사건의 마지막 장은 '당신의 부서'다.** 각 사건파일은 "이 수법을 쓸 수 있는 부서" 로 끝난다.

### 2-2. 동선 원칙
- **시계방향 단일 루프 + 자유 진입 허용**: 정석 루트는 Gate → Archive → Station → Map → Debrief이지만, Archive와 Station은 어느 사건부터 봐도 되도록 **사건 단위로 독립 완결** 시킨다.
- **Archive(아날로그)와 Station(디지털)을 마주보게 배치**: 폴더에서 "무엇"을 본 뒤 몸을 돌리면 바로 스크린에서 "어떻게"를 본다. **같은 사건번호 = 같은 컬러** 로 연결.
- **대기열 분산**: 병목은 오직 Station인데, 90초 콘텐츠 × 4대 = 시간당 최대 160회 상영. Archive를 먼저 거치게 해 자연 분산.

| 소품 | 서류 캐비닛, 기밀 스탬프, 금고, 'TOP SECRET' 봉인 테이프, 아날로그 시계 4개(서울/본사/공장/해외법인 — "작전 지역") |

## 3. 활용사례 전시 방식 — 핵심

> 이 장이 제안서의 핵심이다.
> **"문제 → 사용 데이터 → Copilot/Agent 처리 과정 → 결과물 → 효과"** 를 어떻게 '읽는 것'이 아니라 **'보는 것'** 으로 만들 것인가.

### 3-1. 원칙: 5단계를 '첩보 문법'으로 번역한다

일반 전시는 5단계를 **텍스트 단락** 으로 쓴다. 우리는 5단계 각각에 **고유한 시각 형식(물성·형태·색)** 을 부여해, 글을 읽지 않아도 "지금 어느 단계를 보고 있는지" 알게 한다.

| 비즈니스 단계 | 첩보 세계관 번역 | 시각 형식 (Visual Grammar) | 물성 | 컬러 코드 | 방문객이 얻는 답 |
|---|---|---|---|---|---|
| ① 문제 | **INCIDENT REPORT** (사건 발생 보고) | 타자기 서체의 짧은 사건 기록 + **현장 사진(실제 업무 장면 재연 사진)** + 피해 규모 숫자 | 누런 크래프트지 | 경고 레드 | "누가, 어떤 상황에서 괴로웠나" |
| ② 사용 데이터 | **EVIDENCE** (증거물) | 투명 지퍼백에 담긴 **실물 크기 가상 데이터 출력물**(회의 녹취록 3장, 엑셀, 메일 스레드) + 증거 태그(#E-01, #E-02) | 투명 비닐 + 증거 태그 | 옐로 태그 | "Copilot이 **무엇을 읽었나**" |
| ③ 처리 과정 | **OPERATION LOG** (작전 수행 기록) | **프롬프트 원문(기밀 → 해제)** + 단계별 타임코드 로그(00:00 → 00:47) + 데이터 흐름 화살표 | 검은 Redaction 바 → 해제 | 시안(Copilot) 블루 | "**어떻게 시켰고**, Copilot은 어떤 순서로 처리했나" |
| ④ 결과물 | **RECOVERED DOCUMENT** (회수된 기밀문서) | Copilot이 실제로 만든 결과물의 **실물 출력본**(회의록, 보고서 초안)에 형광펜 주석: "이 줄은 증거 #E-02에서 왔다" | 흰 A4 + 형광 주석 | 화이트 + 형광 | "**무엇이 만들어졌나** (진짜 모양 그대로)" |
| ⑤ 효과 | **MISSION RESULT** (작전 성과) | **Before/After 타임라인 바**(시간 막대 길이 비교) + 요원 평가 스탬프 + 현업 담당자 증언 한 줄 | 금속 플레이트 | 골드 | "**그래서 얼마나 나아졌나**" |

> 핵심 장치: **④ 결과물의 각 문장 옆에 ② 증거물 번호를 표시** 한다. ("이 액션아이템은 녹취록 #E-01, 14:32 발언에서 추출")
> → 방문객은 "AI가 지어낸 게 아니라 **이 데이터에서 이렇게 뽑아냈구나**"를 시각적으로 추적한다. 이것이 "Copilot은 어떻게 활용한 거지?"에 대한 가장 직관적인 답이다.

### 3-2. 표현 방식 4종 (각 사례를 3가지 매체로 '중복 노출')

한 사례를 하나의 매체로만 보여주지 않는다. **같은 사건을 3개의 다른 매체로 보여줘서** 빠른 관람자와 깊은 관람자 모두를 만족시킨다.

#### 표현 방식 A. **Evidence Wall — 붉은 실 사건 보드** (Zone 2 후면 벽, 원거리 3~5m용)

첩보 영화에서 형사가 벽에 사진을 붙이고 붉은 실로 연결하는 장면을 **사례당 1m × 2.4m** 로 구현.

```
  CASE #001 · AGENT BLACK                                                   
  ┌──────────┐          ┌──────────┐          ┌──────────┐          ┌──────────┐          ┌──────────┐
  │ INCIDENT │──red────▶│ EVIDENCE │──red────▶│ OPERATION│──red────▶│RECOVERED │──red────▶│ MISSION  │
  │  photo   │  string  │ zip bags │  string  │ prompt   │  string  │ document │  string  │ RESULT   │
  │ "주간회의 │          │ E-01 녹취 │          │ (redacted│          │ 회의록    │          │ 90분→10분 │
  │  90분,    │          │ E-02 슬라 │          │  → open) │          │ 실물 출력 │          │  ●●●●○   │
  │  회의록   │          │ E-03 메일 │          │          │          │          │          │          │
  │  누락"    │          │          │          │          │          │          │          │          │
  └──────────┘          └──────────┘          └──────────┘          └──────────┘          └──────────┘
```
※ 실제 설치는 위에서 아래로(세로) 5단 배치 — 벽 1m 폭에 사건 1개. 4개 사건이 나란히 서면 **"모든 사건이 같은 5단 구조"** 라는 패턴이 원거리에서도 보인다.

- **원거리 효과**: 통로에서도 "사진 → 증거물 → 문서 → 숫자"로 이어지는 붉은 실이 보인다. 읽지 않아도 '과정이 있다'는 것이 전달됨.
- **실물 증거물**: 증거 지퍼백 안에 실제로 **녹취록 출력물, 엑셀 출력물, 메일 출력물** 을 넣는다. (가상 데이터, 실데이터 형식 그대로) → "회의 녹취록 3장이 들어가면 회의록 1장이 나온다"를 **두께로 체감**.
- **질량 대비 장치**: 사건 #002(문서 탐색)는 증거물 칸에 **A4 500장 묶음(실제 문서 더미)** 을 쌓고, 결과물 칸엔 **답변 카드 1장**. 대비만으로 메시지가 끝난다.

#### 표현 방식 B. **Case File Folder — 손으로 넘기는 사건파일** (Zone 2 렉턴, 근거리 30cm용)

- A3 크래프트 폴더(실물), 사건당 1개, 렉턴에 와이어 고정.
- 폴더를 펼치면 **5개의 탭(INCIDENT / EVIDENCE / OPERATION / RECOVERED / RESULT)** 이 있어 '넘기는 순서 = 처리 순서'.
- OPERATION 탭의 프롬프트는 **검은 반투명 아크릴 슬라이드(Redaction Slider)** 로 가려져 있고, 방문객이 손으로 밀면 원문이 드러난다. → 전원 없는 물리 인터랙션.
- 상세 와이어프레임은 4장 참조.

#### 표현 방식 C. **Operation Replay — 90초 자동 작전 재현** (Zone 3 Station, 디지털)

- 방문객은 **START 하나만** 누른다. 그 뒤 90초는 완전 자동.
- 화면은 실제 Copilot 화면을 **녹화한 것이 아니라 '재구성한 작전 재현 그래픽'** 이다. 이유: ① 실화면은 작은 UI라 전시장에서 안 읽힘 ② 개인정보·보안 이슈 원천 차단 ③ 단계 구분을 연출로 강조 가능.
- 단, 신뢰를 위해 **실제 Copilot UI 클로즈업 컷(블러 처리된 실화면 3~5초)** 을 '현장 CCTV 화면' 컨셉으로 삽입 → "이건 실제로 쓰는 것"이라는 증거 역할.
- 상세 타임라인은 5장 참조.

#### 표현 방식 D. **Layer Lightbox — 겹쳐보는 투명 레이어** (Archive 렉턴 측면, 선택 옵션)

- 라이트박스 위에 **투명 필름 3장** 을 차례로 겹친다.
  - 레이어 1: 원본 데이터(녹취록 전문, 빽빽함)
  - 레이어 2: Copilot이 주목한 부분(형광 하이라이트만 인쇄된 필름)
  - 레이어 3: 최종 결과물 구조(회의록 템플릿 틀)
- 3장을 모두 겹치면 **"원본의 어느 부분이 결과물의 어느 칸으로 갔는지"** 가 정확히 정렬되어 보인다.
- 이 방식은 "AI가 무엇을 근거로 썼는가"라는 **신뢰 질문** 에 가장 강력한 시각적 답이 된다. (Grounding의 시각화)

### 3-3. "처리 과정(③)"을 보여주는 특별 설계 — 블랙박스 열기

방문객이 가장 이해하지 못하는 구간이 ③이다. 다음 4개의 레이어로 쪼개 보여준다.

| 레이어 | 무엇을 보여주나 | 시각화 방식 | 예: CASE #001 회의요약 |
|---|---|---|---|
| **3-a. 트리거** | 사람이 무엇을 했나 (클릭 1번? 프롬프트 1줄?) | 손가락 아이콘 + 실제 클릭 위치 | "Teams 회의 종료 후 Copilot 패널 열기" |
| **3-b. 지시(프롬프트)** | 정확히 어떤 문장으로 시켰나 | **프롬프트 원문 전체 공개** (Redaction 해제 연출) | "이번 회의의 결정사항, 담당자별 액션아이템, 기한, 미결 이슈를 표로 정리해줘. 담당자가 명시되지 않은 항목은 '미지정'으로 표시해." |
| **3-c. 참조 데이터** | Copilot이 실제로 열어본 것 | 증거물 번호가 **스캔 라인** 과 함께 점등 | E-01 회의 트랜스크립트 / E-02 공유된 PPT / E-03 직전 회의 메일 |
| **3-d. 사람의 검토** | 사람이 어디를 고쳤나 (Human-in-the-loop) | 빨간 교정 펜 마크업 | "기한 1건 수정, 담당자 1명 추가 → 발송" |

> **3-d는 반드시 넣는다.** "AI가 다 해준다"가 아니라 "**AI가 초안 80%, 사람이 검토 20%**" 를 보여줘야 현업이 "우리도 할 수 있다"고 믿는다. 이것이 과장 없는 전시의 신뢰 장치다.

### 3-4. "효과(⑤)"를 숫자 나열이 아니라 '체감'으로 보여주기

| 기존 방식 | 이번 방식 |
|---|---|
| "업무시간 85% 절감" | **시간 막대 실물 비교**: 90cm 길이 레드 막대(90분) vs 10cm 골드 막대(10분)를 벽에 나란히 부착 |
| "연간 1,200시간 절감" | **"되찾은 시간" 환산**: "= 팀원 1명이 매주 금요일 오후를 돌려받음" 같은 생활 언어 |
| "만족도 4.5점" | **현업 담당자 증언 한 줄 + 사원 실루엣 + 부서명** ("회의록 쓰느라 퇴근 못 하던 날이 없어졌어요" — 영업기획팀 ○○○ 대리) |
| 정확도 지표 | **요원 평가 스탬프**: SPEED ●●●●● / ACCURACY ●●●●○ / HUMAN CHECK REQUIRED ●●○○○ — 한계도 정직하게 표시 |

## 4. 사례 카드 디자인 — CASE #001 와이어프레임

사례 카드는 3가지 포맷으로 제작한다. 정보 구조(5단계)는 **세 포맷 모두 동일** 하게 유지하고, 밀도만 다르다.

|---|---|---|---|---|
| **F1. Case File Folder** | A3 펼침(A2) 폴더, 5탭 | Archive 렉턴 | 30~50cm | ★★★★★ (전체 원문) |

### 4-1. F1. Case File Folder — 표지 (닫힌 상태)

## 5. 인터랙션 없이 참여감을 주는 연출

### 5-1. 설계 원칙: **"조작은 0에 가깝게, 역할은 100%로"**

참여감은 '조작의 양'이 아니라 **'내가 이 일의 주체'라는 착각** 에서 온다. 그래서
- 방문객이 하는 행동은 **태그 1번, 버튼 1번, 슬라이더 밀기, 스티커 1장, 도장 1번** 으로 제한하고,
- 각 행동에 **세계관적 의미** (권한 획득 / 기밀 해제 / 작전 지역 지정 / 임무 인계)를 부여한다.

| 행동 | 소요 | 세계관 의미 | 운영 부담 |
|---|---|---|---|
| 사원증 태그 | 2초 | 신원 확인 → 열람 권한 획득 | 연출용 리더기 (무조건 통과) |
| START 버튼 | 1초 | 기밀 해제 명령 | 아케이드 버튼 1개, 키보드 입력 신호 |
| Redaction 슬라이더 밀기 | 3초 | 직접 검은 줄을 걷어냄 | 전원 불필요 |
| 지도에 핀 스티커 | 10초 | 다음 작전 지역 지정 | 스티커 보충만 |
| 의뢰서 투입 + 도장 | 30초 | 임무 인계 | Desk Officer 1명 |

### 5-2. Declassify Station — "START 한 번, 90초 자동 시퀀스" 상세 콘티 (CASE #001)

**하드웨어**: 43" 세로 디스플레이 + 대형 아케이드 버튼(빨간색, 투명 커버 덮개 — **커버를 젖히고 누르는 동작** 이 '발사 버튼' 같은 긴장감을 줌) + 사건 선택 버튼 4개(사건 번호, 컬러별) + 미니 PC(로컬 재생, 네트워크 불필요).

**대기 화면(Idle)**: 4개 사건 폴더가 잠긴 채 회전. "SELECT CASE → LIFT COVER → PRESS START" 3단 안내. 30초마다 무작위로 짧은 '해제 맛보기'(검은 줄 1개만 걷혔다가 다시 덮임).

**연출 원칙**
- **자막 우선(무음에서도 100% 이해)**: 전시장 소음을 전제로, 모든 정보는 화면 텍스트로 완결. 사운드는 '분위기' 역할만.
- **90초 상한**: 부스 체류 데이터상 단일 스크린 집중 한계는 60~120초. 90초가 '끝까지 보는' 최적 길이.
- **같은 구조 × 4건**: 사건 하나를 보고 나면 두 번째 사건부터는 구조를 이미 알기 때문에 **내용에만 집중** 한다. 반복이 학습이 된다.
- **동일 시퀀스의 '그림자 상영'**: Station 상단에 사이니지(55")를 달아, 지금 누군가 재생 중인 작전을 **확대 미러링**. 뒤에서 기다리는 사람도 함께 관람 → 대기 시간 자체가 관람 시간이 됨.

| 2 | **보안 등급 업그레이드 스탬프** | 사건파일 렉턴마다 고유 스탬프(사건 컬러). 4개 모두 찍으면 Clearance Level 4 → Debrief에서 **"TOP SECRET CLEARED" 도장** | 수집·완성 욕구 (스탬프 랠리) |

| 4 | **역(逆)파쇄기** | 파쇄된 종이 조각(=흩어진 데이터)이 투명 통에 가득 → 버튼 없이 상시 루프 영상으로 조각이 모여 한 장의 보고서가 되는 장면 상영 (CASE #003 옆) | 직관적 은유 — "흩어진 정보를 모은다" |
| 5 | **지금 이 순간 작전 카운터** | Intelligence Map 상단 LED: "오늘 기밀 해제된 사건 수: 1,247 / 의뢰 접수된 부서: 38" (Station 재생 수, 의뢰서 투입 수 실시간 집계) | 집단 참여감, 사회적 증거 |
| 6 | **현장 무전 브리핑** | 매시 정각 2분간 부스 스피커로 "본부에서 알린다, 신규 작전 지역 발생…" 내레이션 + Handler(스태프)의 30초 라이브 미니 브리핑 | 이벤트성, 군중 형성 |
| 7 | **사건 의뢰서 투입구** | "당신 부서의 미해결 사건을 신고하세요" 엽서 → 금속 우편함 'CASE INTAKE'에 투입. 투입 시 센서가 반응해 "CASE RECEIVED #0XX" 번호가 LED에 표시 | 자기 문제의 외재화, 후속 연결 |

## 6. Secret Agent 테마 장치

테마 장치는 '장식'이 아니라 **정보 구조를 강화하는 기능** 을 가져야 한다. 각 장치가 어떤 정보 기능을 하는지 함께 설계한다.

### 6-1. 보안등급(Clearance Level) — **정보의 깊이를 등급화**

| 등급 | 명칭 | 공개 정보 | 획득 방법 | 대응 매체 |
|---|---|---|---|---|
| **L1** | CONFIDENTIAL | 사건명, 요원, 결과 1줄 | 입구 ID 카드 발급 | 폴더 표지, Attract 영상 |
| **L2** | SECRET | 문제 + 사용 데이터 | 사건파일 열람 | 폴더 ①② |
| **L3** | TOP SECRET | **프롬프트 원문 + 처리 과정** | Station START / 슬라이더 해제 | 폴더 ③, Operation Replay |
| **L4** | EYES ONLY | 적용 체크리스트 + 따라 쓸 프롬프트 | 사례 공개 화면 도달 | STEAL THIS PROMPT 화면 |

→ 보안등급이 곧 **"정보를 얕은 것부터 깊은 것 순서로 보여주는 정보 설계"** 다. 방문객은 등급이 오를수록 더 구체적인 '수법'을 얻는다. 핵심은 **가장 높은 기밀 = 프롬프트와 처리 과정** 으로 설정했다는 것 — 즉 세계관이 "How가 가장 귀중하다"는 메시지를 구조적으로 전달한다.

### 6-2. 기밀문서(Redaction) — **"가려져 있다 → 열린다"의 반복**

- 모든 프롬프트·데이터 소스명은 처음엔 **검은 줄(▓▓▓)** 로 가려져 있다.
- 해제 수단: 물리 슬라이더(폴더) / 자동 타이핑 해제(스크린) / UV 라이트(숨은 근거).
- 의미: 사람은 **가려진 것을 보고 싶어 한다**. 가장 중요한 정보(프롬프트)를 일부러 가려서 오히려 **주목도를 최대화** 한다.

### 6-3. 사건파일(Case File) — **사례 표준화 포맷**

- 모든 사례를 **CASE #001~#004** 번호 체계 + 동일 5탭 구조로 표준화.
- 사례 제출 부서는 부록의 **"사건 보고 양식"** 만 채우면 자동으로 전시 콘텐츠가 됨 → 콘텐츠 제작 효율 + 사례 간 비교 가능성.
- 사건명 작명 규칙: **"The ___ 사건"** (예: 사라진 액션아이템 사건 / 500장의 미로 사건 / 월말의 악몽 사건 / 3,000개의 목소리 사건)

### 6-4. 조사보고서(Investigation Report) — **결과물(④)의 프레임**

- Copilot이 만든 결과물을 "회수된 기밀문서(RECOVERED DOCUMENT)"로 명명하고 **실물 출력본** 으로 제시.
- 결과물 위에 **조사관의 형광펜·포스트잇 주석** ("이 줄은 E-01 14:32 발언에서 추출", "이 기한은 사람이 수정") → 결과물의 **출처와 사람의 개입이 동시에 보인다**.

### 6-5. Intelligence Map — **"우리 부서도 할 수 있나?"의 시각적 답**

4m × 2.4m 벽면 지도. 지리 지도가 아니라 **회사 조직도/업무 기능 지도** 를 첩보 작전 지도처럼 디자인.

```
 ┌──────────────────────── AXIA INTELLIGENCE MAP ─────────────────────────┐
 │  LIVE: 1,247 cases declassified today | 38 departments requested       │
 │                                                                        │
 │   [SALES]──────────[MARKETING]────────[CUSTOMER SVC]                   │
 │    ● #001 BLACK      ○ RED applicable    ● #004 RED                    │
 │    ○ GOLD applicable ○ GOLD applicable   ○ BLUE applicable             │
 │        │                  │                   │                        │
 │   [FINANCE]──────────[HR]──────────────[R&D]──────────[PRODUCTION]     │
 │    ● #003 GOLD        ● #002 BLUE       ○ BLACK         ○ BLUE         │
 │    ○ BLACK            ○ BLACK           ○ BLUE          ○ GOLD         │
 │                                                                        │
 │   ● = mission complete (case on display)   ○ = mission possible        │
 │   📍 red pins = visitor requests (grows during the day)                │
 │                                                                        │
 │   LEGEND: BLACK=meetings BLUE=search GOLD=reports RED=VOC              │
 └────────────────────────────────────────────────────────────────────────┘
```

- **● 작전 완료 지역**: 전시 중인 사례가 나온 부서.
- **○ 작전 가능 지역**: 같은 수법을 바로 적용할 수 있는 부서 (사전 분석으로 표기) → **"우리 부서도?"에 대한 답이 지도에 미리 표시** 되어 있다.
- **📍 방문객 핀**: 방문객이 자기 부서에 핀을 꽂고, 원하는 요원 컬러 스티커를 붙임. 오후가 될수록 지도가 붉게 채워지는 것 자체가 **AX 확산 수요의 시각화** 이며, 행사 후 보고 자료가 된다.

### 6-6. 기타 장치

| 장치 | 기능 |
|---|---|
| **요원 프로필 도시에(Dossier)** | 각 Agent의 "특기 / 사용 도구(Teams·SharePoint·Excel·Outlook) / 취약점(이럴 땐 사람이 꼭 확인)" — Copilot 기능의 강점과 한계를 캐릭터 설정으로 정직하게 전달 |
| **CCTV 모니터 벽** | 소형 모니터 4대에 실제 Copilot 화면 클로즈업(블러·가상 데이터) 루프 → "실제 작동 화면" 증거 |
| **작전 시계** | "본사 / 공장 / 해외법인" 시각 표시 → 사례가 전사적이라는 인상 |
| **기밀 봉인 테이프** | 폴더·부스 모서리마다 "DECLASSIFIED FOR AX DAY 2026" 테이프 — 포토 스팟 기능 겸함 |
| **포토 존 'MOST WANTED'** | "WANTED: 반복 업무" 수배 포스터 앞에서 요원 ID를 들고 촬영 → SNS/사내 게시판 바이럴 |

## 7. 최종 권장안

### 7-1. 검토한 3개 안

| 구분 | **A안. Full Digital HQ** | **B안. Analog Case Archive** | **C안. Hybrid: Declassify Station + Evidence Wall** |
|---|---|---|---|
| 개요 | 대형 LED 월 + 터치 테이블 + 개인별 태블릿 열람. 모든 사례를 디지털 인터랙티브로 | 사건파일 폴더·증거 보드·실물 소품 중심의 아날로그 전시 | 아날로그 사건파일/증거 벽(이해) + START 1버튼 자동 재현 스크린(과정) |
| "과정"의 전달력 | ★★★★☆ 애니메이션으로 과정 표현 우수 | ★★★☆☆ 정적이라 '처리 흐름'의 시간성이 약함 | **★★★★★ 실물 증거(양감) + 자동 재현(시간성) 결합** |
| 직관성 | ★★★☆☆ 터치 UI 학습 필요, 정보 과잉 위험 | ★★★★☆ 손으로 넘기는 직관성 | **★★★★★** |
| 대기열 | ★★☆☆☆ 터치 기기 점유 시간 길어 병목 | ★★★★★ 동시 다수 열람 | **★★★★☆** 90초 고정 + 미러링 |
| 운영 리스크 | 높음 (터치 오작동, 네트워크, 콘텐츠 버그) | 매우 낮음 | **낮음** (로컬 재생, 버튼 1개) |
| 제작 비용 | 높음 | 낮음 | 중간 |
| 포토/화제성 | 중간 | 중간 | **높음** (증거 벽 + 붉은 실 + 스탬프) |
| 행사 후 재활용 | 낮음 | 중간 | **높음** (영상은 사내 포털·교육용, 폴더는 순회전시) |

### 7-2. 최종 권장: **C안 — "COPILOT SECRET AGENT HQ : Declassify Station + Evidence Wall"**

#### 선정 이유 5가지

**① 5단계 흐름을 가장 정확하게 '보이게' 만든다.**
- 아날로그(증거 지퍼백, 500장 문서 더미, 3,000건 롤 페이퍼)는 **데이터의 '양'과 결과물의 '압축'** 을 몸으로 느끼게 하고,
- 디지털 자동 재현은 **처리의 '순서와 시간'** 을 보여준다.
- 둘 중 하나만으로는 "무엇을 읽고 → 어떻게 시켜서 → 무엇이 나왔는지"가 완결되지 않는다.

**② "Copilot은 어떻게 활용한 거지?"에 정면으로 답한다.**
- 전시의 최고 기밀을 **프롬프트 원문과 처리 과정** 으로 설정했기 때문에, 방문객이 가장 오래 보고 가장 많이 가져가는 정보가 바로 'How'가 된다. 화면의 "STEAL THIS PROMPT"는 다음 날 업무로 이어진다.

**③ 체험존의 모든 운영 리스크를 제거한다.**

| 체험존 리스크 | C안의 해결 |
|---|---|
| 라이선스 | 실시간 Copilot 미사용. 사전 제작 영상·인쇄물로만 운영 |
| 계정 | 로그인 없음. 사원증 태그는 연출용 리더기 |
| 기업 데이터 접근 | 모든 증거물은 **실데이터 형식을 복제한 가상 데이터** |
| 개인정보 | 코드네임 랜덤 카드, 이름·연락처 미수집 (의뢰서는 부서명만, 연락처는 선택) |
| 운영 복잡도 | 조작부는 버튼 1개 × 4대. 미니 PC 로컬 루프 재생, 네트워크 불필요 |
| 대기열 | 90초 고정 상영 × 4대 + 상단 미러링 + 아날로그 동시 열람 → 피크 대기 5분 이내 |

**④ 처리량과 체류시간의 균형이 맞다.**
- Station 4대 × 시간당 40회(90초 + 전환 여유) = **시간당 160회 상영**.
- Archive 폴더 4개 + Evidence Wall은 동시 20명 이상 열람 가능.
- 빠른 관람객(3분: 벽 + Station 1회), 깊은 관람객(15분: 전 사건 + 스탬프 완주) 모두 수용.

**⑤ 행사 이후 자산이 남는다.**
- Operation Replay 영상 → 사내 포털 "Copilot 수법 라이브러리", 신규 입사자 교육.
- 사건파일 폴더 → 각 사업장 로비 순회 전시.
- Intelligence Map 핀 데이터 + 사건 의뢰서 → **차기 Copilot 확산 대상 부서 리스트** (AX 추진 조직의 실질적 KPI).

#### 권장안의 핵심 경험 한 줄
> **"손으로 증거를 만지고, 버튼 하나로 기밀을 해제하고, 프롬프트 한 장을 훔쳐서 나간다."**
